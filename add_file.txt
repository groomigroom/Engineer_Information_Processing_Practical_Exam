sales = {}

## 2. 상품별 매출 집계 (반복문)

for order in orders:


* 역할: orders 리스트에 있는 5개의 주문 딕셔너리를 하나씩 꺼내어 반복 루프를 돌립니다.

    product = order[""product""]


* 역할: 현재 주문의 상품명(예: ""bbang"")을 추출하여 product 변수에 저장합니다.

    revenue = order[""qty""] * order[""price""]


* 역할: 현재 주문의 수량(qty)과 단가(price)를 곱해 해당 주문의 매출액을 계산합니다.

    sales[product] += revenue


* 역할: 계산된 매출액(revenue)을 해당 상품의 기존 누적 매출에 더해줍니다.

	파이썬			"anext()는 비동기 반복자(Asynchronous Iterator)에서 다음 값을 가져오는 내장 함수입니다. 동기 환경의 next() 함수와 동일한 역할을 하지만, I/O 작업 중에도 프로그램이 블로킹되지 않도록 코루틴(Coroutine)을 반환하는 것이 특징입니다.1. 주요 특징 및 문법구문: anext(iterator) 또는 anext(iterator, default)동작 방식: 비동기 이터레이터의 __anext__() 메서드를 호출하여 다음 값을 반환합니다.종료: 더 이상 가져올 데이터가 없으면 StopAsyncIteration 예외가 발생합니다.기본값 설정: default 값을 제공하면, 반복자가 소진되었을 때 StopAsyncIteration 에러 대신 지정한 기본값을 반환합니다.2. 사용 예시anext()는 주로 웹소켓 스트림, 비동기 파일 읽기 등 데이터가 비동기적으로 도착하는 환경에서 직접 데이터를 소비해야 할 때 사용됩니다.pythonimport asyncio

async def my_async_generator():
    for i in range(3):
        await asyncio.sleep(1)  # 비동기 I/O 대기
        yield i

async def main():
    # 비동기 반복자 생성
    async_iter = my_async_generator()
    
    # anext()로 직접 하나씩 가져오기
    try:
        while True:
            # 반환되는 것이 코루틴이므로 await를 사용해야 합니다.
            value = await anext(async_iter)
            print(f""가져온 값: {value}"")
    except StopAsyncIteration:

	c언어 문법		"ptr = (자료형*)malloc(할당할 크기);

할당할 크기는 byte 단위이다. 안전하게 사용하기 위해서는 할당할 크기를 자료형 크기의 정수 배로 하는 것이 좋다.

int *ptr;
ptr = (int*)malloc(배열의 길이 * sizeof(int));

이렇게 할당하고 나면 ptr[5]와 같이 사용할 수 있다.

사실 동적 할당에서 형변환은 필요하지 않다. 아래처럼 쓰는 것이 보통이다.
ptr = malloc(배열의 길이 * sizeof(int));

과거에는 void *라는, 모든 포인터를 포괄하는 포인터 자료형이 없었기 때문에 malloc의 반환 자료형은 char *였고, 다른 타입의 변수에 대입하기 위해 명시적으로 형변환을 해야 했다. 이후 1989년에 void *가 추가되고 malloc의 반환 자료형이 void *로 변경되면서 형변환이 필요 없게 되었다.

그러나 예전부터 써온 관습도 있고, 컴파일러에 따라 경고 수준이 높을 경우 경고를 출력하는 데다, C++은 C와 다르게 void *형에게도 명시적인 형변환을 요구하기 때문에, 대부분의 C 교재나 강의에서는 malloc 함수의 값을 형변환해서 쓰도록 가르치고 있다.[20]

위의 예제에서 ptr의 자료형이 변경된다면(예를 들어 int에서 double로) sizeof의 피연산자도 바꿔야 하는 번거로움이 생긴다.(sizeof(int)에서 sizeof(double)로) 이 문제를 해결하는 근본적인 방법은 sizeof의 피연산자를 자료형 대신 변수로 하는 것이다.
ptr = malloc (배열의 길이 * sizeof *ptr);


동적 할당된 공간은 자동으로 해제되지 않기 때문에, 더 이상 필요 없으면 프로그래머가 직접 해제해야 한다. 필요할 때마다 메모리를 계속 받으면서 해제하는 작업을 하지 않으면, 할당받았지만 접근할 수 없는 메모리 공간이 점점 늘어나면서 심할 경우 프로그램이 그대로 뻗는 경우도 있다.[21][22]
메모리 해제는 free 함수로 할 수 있다.

free (ptr);"

import fs from 'fs/promises';
import { URL } from 'url';

const app = http.createServer(async (request, response) => {
  try {
    // 1. URL 분석 (최신 WHATWG URL API 사용)
    const baseURL = `http://${request.headers.host}`;
    const { pathname, searchParams } = new URL(request.url, baseURL);
    const id = searchParams.get('id');

    // 2. 라우팅 처리
    if (pathname !== '/') {
      response.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
      return response.end('Not found');
    }

    // 3. 파일 목록 읽기 (Promise 기반 fs.readdir)
    const filelist = await fs.readdir('./data');
    
    // 배열 메서드(map, join)로 깔끔하게 HTML 리스트 생성
    const list = `<ul>${filelist.map(file => `<li><a href=""/?id=${file}"">${file}</a></li>`).join('')}</ul>`;

    // 4. 상황별 데이터 설정 (조건부 렌더링)
    let title = 'Welcome';
    let description = 'Hello, Node.js';

    if (id) {
      title = id;
      // Promise 기반 fs.readFile 사용
      description = await fs.readFile(`data/${id}`, 'utf8');
    }

    // 5. HTML 템플릿 생성 및 응답
    const template = `
      <!doctype html>
      <html>
      <head>
        <title>WEB1 - ${title}</title>
        <meta charset=""utf-8"">
      </head>
      <body>
        <h1><a href=""/"">WEB</a></h1>
        ${list}
        <h2>${title}</h2>
        <p>${description}</p>
      </body>
      </html>
    `;

    response.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
    response.end(template);

  } catch (error) {
    // 에러 발생 시 500 응답 처리
    response.writeHead(500, { 'Content-Type': 'text/plain; charset=utf-8' });
    response.end('Internal Server Error');
  }
});

app.listen(3000, () => {
  console.log('Server running at http://localhost:3000/');
});
